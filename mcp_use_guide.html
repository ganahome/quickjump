MCP (Model Context Protocol) 가이드

AI에이전트 모델들로그인후 > 내가 000 프로그램을 콘트롤 하려고 하는데 MCP를 사용해서 컨트롤 하게 해줘라고 하면 리드해준다

AI 에이전트와 로컬 데스크탑 프로그램(블렌더, 파일 시스템 등)을 연동하기 위한 MCP의 핵심 개념, 비용 구조 및 실전 예제 정리 문서입니다.

1. 비용 지불 구조

정답: 대부분의 경우 LLM 서비스(AI 에이전트) 1군데에만 비용을 지불하게 됩니다.
  • 블렌더 & MCP 모듈 (무료): 오픈소스 프로그램인 블렌더(Blender)와 이를 연결해 주는 CODEX의 MCP 클라이언트/서버 모듈은 개발 도구이거나 오픈소스 플러그인일 가능성이 높습니다. 따라서 블렌더나 MCP 모듈 자체에 비용을 내지는 않습니다.
  • AI 에이전트 / LLM 모델 (유료): 블렌더를 제어하는 주체인 AI 에이전트(예: Claude, ChatGPT, OpenAI API 등)가 토큰을 소비하며 작동하므로, 이 LLM 서비스 이용료만 지불하시면 됩니다.

2. MCP 올바른 작동 프로세스 (주체 교정)

MCP 구조에서는 AI 에이전트가 '클라이언트(접속하는 주체)'가 되고, 내 PC에 설치된 데스크탑 프로그램이 '서버(기다리는 주체)'가 됩니다.

단계 올바른 MCP 작동 프로세스
1단계 (서버 준비) 내 PC(또는 블렌더)에 MCP 서버 역할을 할 모듈을 설치하고 실행한다.
내 PC 측에 MCP 모듈을 설치하여 AI가 내 프로그램을 제어할 수 있도록 '서버'를 대기시키는 단계입니다.
2단계 (연결 설정) AI 에이전트(클라이언트) 설정에서 내 PC의 MCP 서버 주소를 연결(Connect)한다.
Claude Desktop 등의 설정 파일에 MCP 서버의 주소나 경로를 등록하여 AI가 내 PC와 대화할 수 있게 연결해 줍니다.
3단계 (최종 사용) AI 에이전트가 도구(Tools)를 인식한 것을 확인하고 명령을 내린다.
연결이 완료되면 AI 에이전트 화면에 제어 플러그인이 활성화되며, 명령을 내리면 AI가 내 PC의 프로그램을 직접 조작합니다.

3. 컨트롤 사용 예제 (내 PC 파일 제어하기)

현재 가장 대중적인 AI 에이전트인 Claude Desktop을 활용하여 내 PC의 특정 폴더를 AI가 직접 제어하는 예제입니다.

1단계: 내 PC에 MCP 서버 준비하기

제어할 내 PC의 작업 공간 폴더를 하나 생성합니다. (예: C:\mcp_workspace)

2단계: AI 에이전트에 MCP 서버 연결하기

Claude Desktop의 설정 파일(%APPDATA%\Claude\claude_desktop_config.json)을 메모장으로 열고 아래와 같이 수정합니다.

{
  "mcpServers": {
    "my-pc-filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\mcp_workspace"
      ]
    }
  }
}
3단계: AI 에이전트에서 연결 확인 후 사용하기

Claude Desktop을 재시작한 후, 우측 하단의 플러그인 아이콘(Tools)이 활성화되었는지 확인합니다. 이후 다음과 같이 명령을 내릴 수 있습니다.

명령 예시: "지정한 폴더에 todo.txt 파일을 만들고, 오늘 할 일인 '블렌더 MCP 연동 테스트하기'를 적어줘."
